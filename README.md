# JalenOS

This project will help you move the needle everyday. The goal is build a personalized assistant tailored to my lifestyle that will make me more productive and allow me to spend less time researching.

There are plenty of personal assistant apps, but nothing that is personalized to exactly what I think would make a person with my ambitions more productive. 

We only get one life. I want to enjoy mine. I think this will reduce the friction between learning, planning, executing, and building.
